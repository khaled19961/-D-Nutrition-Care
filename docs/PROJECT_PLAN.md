# D-Nutrition-Care — Project Plan

## Vision
Build a bilingual Arabic/English nutrition-care platform that connects patients with qualified nutritionists, supports booking, nutrition programs, follow-up, educational content, payments, and administration.

## Product principles
- Arabic RTL first, English LTR supported.
- Mobile-first responsive UX.
- Clear patient journey from discovery to booking to follow-up.
- Original design and implementation; no literal copying of third-party websites.
- Privacy and least-privilege access for patient data.
- SEO-ready public pages.
- Modular architecture that can migrate away from any single hosting/provider.

## MVP
1. Public homepage and service discovery.
2. Nutritionist directory and profiles.
3. Authentication and user profiles.
4. Availability and appointment booking.
5. Nutrition programs and patient assignments.
6. Progress tracking.
7. Goals and reviews.
8. Articles/categories.
9. Notifications.
10. Admin dashboard.
11. Basic payment records and integration boundary.
12. Arabic/English localization.

## Phase 2
- Online video consultations.
- In-app messaging.
- Subscriptions/packages.
- Coupons.
- Advanced analytics.
- Automated reminders.
- Mobile app/API clients.

## Definition of done
- Production build passes.
- Database migrations run cleanly.
- RLS policies protect private data.
- Core patient/nutritionist/admin journeys work.
- Forms validate client and server side.
- SEO metadata and sitemap are present.
- Arabic RTL and English LTR are tested.
- Error, loading and empty states exist.
- No secrets are committed.
