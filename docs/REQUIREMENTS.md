# Requirements

## Patient
- Register/login/logout.
- Maintain profile.
- Browse nutritionists and services.
- View availability.
- Book/cancel appointments according to policy.
- View assigned programs and meals.
- Record/view progress.
- Manage goals.
- Favorite nutritionists.
- Review completed appointments.
- Receive notifications.
- Read articles.

## Nutritionist
- Maintain professional profile.
- Manage specialties and services.
- Publish availability.
- View permitted appointments.
- Create/manage nutrition programs.
- Assign programs to patients.
- Record follow-up measurements.
- Review patient progress.
- Receive notifications.

## Admin
- Manage users and roles.
- Verify nutritionists.
- Manage specialties/categories.
- Moderate reviews/articles.
- Review appointments and payment records.
- View operational analytics.

## Non-functional
- Accessible UI.
- Fast public pages.
- Secure authentication.
- Strong authorization.
- Audit-friendly timestamps.
- Internationalization.
