# SEO

## Public pages
- Unique title and description per route.
- Canonical URLs.
- Open Graph metadata.
- Structured data where appropriate.
- Arabic and English alternates.
- XML sitemap.
- robots.txt.
- Fast server-rendered/static public content.

## Content
Articles target genuine search intent and provide useful, original information. Avoid keyword stuffing.

## Technical
Stable slugs, redirects for changed slugs, semantic headings, optimized images, internal linking and indexable public profiles.
