# UI/UX Specification

## Visual direction
Modern, calm, trustworthy and health-oriented. Original visual identity for D-Nutrition-Care.

## Navigation
Desktop: logo, الرئيسية, الأخصائيون, البرامج, المقالات, من نحن, contact/booking CTA, language switch, account.
Mobile: compact header with menu and primary booking CTA.

## Core screens
- Home
- Nutritionist listing
- Nutritionist detail
- Service detail
- Booking
- Login/register
- Patient dashboard
- Program detail
- Progress tracking
- Articles/list/detail
- Nutritionist dashboard
- Admin dashboard
- Legal pages

## UX states
Every data-driven view must support loading, empty, error and success states.

## RTL
Arabic is the primary visual direction. Avoid hard-coded left/right positioning where logical start/end can be used.

## Accessibility
Keyboard navigation, visible focus states, semantic HTML, labels, adequate contrast and meaningful error messages.
