# User Flows

## Patient booking
Home -> Nutritionists -> Nutritionist profile -> Service -> Available slot -> Login/Register -> Booking details -> Payment if enabled -> Confirmation -> My appointments.

## Follow-up
Login -> Dashboard -> Active program -> Progress -> Add measurement -> History -> Nutritionist review.

## Nutritionist onboarding
Register -> Choose nutritionist role -> Professional profile -> Credentials -> Pending verification -> Admin verification -> Public profile.

## Content
Visitor -> Articles -> Category/article -> Related articles -> CTA to nutritionist/service.

## Admin
Login -> Admin dashboard -> Users / Nutritionists / Appointments / Content / Reviews / Payments -> Detail -> Action -> Audit timestamps.
